# Estudos Java

Repositório com exercícios de Java, feitos durante meus estudos na área de Análise e Desenvolvimento de Sistemas (ADS), com foco em lógica de programação e Programação Orientada a Objetos (POO).

## 📁 Estrutura do projeto

Projeto criado no Apache NetBeans (Maven).

### `ConversorTemperatura.java`
Programa de conversão de temperatura de Fahrenheit para Celsius. O usuário digita um valor em °F e o programa calcula e exibe o valor correspondente em °C.

### `Cilindro.java`
Calcula a área total e o volume de um cilindro, a partir do raio e da altura informados pelo usuário.

### `Distancia.java`
Calcula a distância entre dois pontos (A e B) em um plano cartesiano, a partir das coordenadas informadas pelo usuário.

## 🛠️ Tecnologias

- Java
- Apache NetBeans IDE
- Maven

## 🎯 Objetivo

Repositório voltado para prática e consolidação de lógica de programação, estruturas condicionais, entrada de dados via `Scanner` e uso da biblioteca `Math`.
